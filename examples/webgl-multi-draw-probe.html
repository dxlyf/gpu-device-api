开发者探针：WEBGL_multi_draw 可用性 / 逐像素一致性 / CPU 提交耗时

⚠️ 这一页是开发者探针，不是使用示例：它不导入本库，只读原生 WebGL2 的扩展面与行为，用来回答「本机这个 GL 后端到底有没有 WEBGL_multi_draw、 它能不能真的把 N 次 draw 压成一次且画出逐字节相同的画面、单次调用能承载多大 的 drawcount、以及 CPU 提交耗时差多少」。结论写在 data-* 上供 scripts/verify-headless.mjs 抓取。

查询参数：?case=arrays|elements|instanced|instanced-elements（默认 arrays）、&mode=single|multi（只有它影响 canvas 上的可见画面，供合成截图比对）、&scene=1024（可见画面的四边形数）、&bench=0（跳过耗时基准）、&big=0（跳过 N=10000 的一致性检查）、&submitReps=11&finishReps=7（时间样本个数）。

无头抓取（WebGL2 软件光栅化；注意 --enable-unsafe-webgpu 不能与 swiftshader 那组同时加）： 

node scripts/verify-headless.mjs --chrome "<chrome>" --timeout 300000 \
  --url "http://localhost:<port>/examples/webgl-multi-draw-probe.html" --wait probeResult \
  -- --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader

截图比对（真实合成截图）：?case=arrays&mode=single&bench=0&big=0 与 ?case=arrays&mode=multi&bench=0&big=0 各截一张，再用 node scripts/compare-screenshots.mjs a.png b.png --crop <canvas rect>。
